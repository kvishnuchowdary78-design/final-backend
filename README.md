# 🚀 Scalable Backend System (MeetMux Capstone)

## 📌 Features
- Activity Management API
- Redis Caching for performance
- Worker Threads for CPU tasks
- WebSockets for real-time updates
- Rate Limiting & Security (Helmet)
- Load Testing using Autocannon

## 🛠️ Tech Stack
- Node.js
- Express
- MongoDB
- Redis
- Socket.io

## 🚀 How to Run

1. Start Redis:
   cd C:\redis
   redis-server.exe

2. Start Server:
   node index.js

## 📊 Performance
Tested using Autocannon:
- Improved throughput using Redis caching
- Reduced latency significantly
